# Webpage Screenshot Taker (Scheduler)

A C# WPF (MVVM & Prism) desktop application and Windows Service for automated webpage screenshot capture. Originally built for a client to replace a costly third-party service (Stillio), this solution schedules and captures webpage screenshots at specific times daily.

## Features
- **Automated Screenshot Scheduling** – Capture webpage screenshots at predefined times.
- **WPF Desktop App** – User-friendly interface for managing URLs and schedules.
- **Windows Service** – Runs in the background to ensure timely captures.
- **SQLite Database** – Shared storage for configuration and logs.

Built with **C#**, **WPF (MVVM & Prism)**, and **SQLite**.
